How to get the Client ID (one time)

1. Google Cloud → Credentials (same project as your service account).
2. Create credentials → OAuth client ID. If asked, configure the consent screen: type External, add an app name + your email, save, and add your own email under Test users.
3. Application type Web application. Under Authorized JavaScript origins add: https://premth4kur.github.io
4. Create, copy the Client ID (ends in .apps.googleusercontent.com), paste it above. It's not a secret — safe to use in a page.
